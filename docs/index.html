Methodology

  • Haircut = 1 − mostRecentValuationAmount / valuationSecuritizationAmount. Pool and group haircuts are value-weighted.
  • Appraisal velocity compares mostRecentValuationAmount across matched assetNumber pairs reporting a valuation in both periods; newly appraised loans are tracked separately.
  • Migration matrix classifies active prior-period loans into Healthy (DSCR ≥ 1.25x and occupancy ≥ 85%), Watch (1.00x–1.25x or 75%–85%), and Distressed (DSCR < 1.00x or occupancy < 75%), plus Resolved/Liq when balance drops to zero.
  • Maturity wall = balance with maturityDate in 2026–2028 (inclusive), over total current balance (currentEndingScheduledBalanceAmount).
  • Distress: DSCR (mostRecentDebtServiceCoverageNetOperatingIncomePercentage) < 1.00x; occupancy (mostRecentPhysicalOccupancyPercentage) < 75%; special servicing = a special-servicer transfer date is reported; 30+d delinquency uses paymentStatusLoanCode.
  • Incremental realized loss = current minus prior realizedLossToTrustAmount per loan so previously liquidated loans are never double-counted.
